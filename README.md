# Slump Sports home-screen launcher

Streamlit Cloud cannot serve a custom `apple-touch-icon`, so this tiny static site holds the
icon and opens the app at:

https://sportstool-app-uwvhxnna5fdzkf9y.streamlit.app

On iPhone: open this launcher page, then Share → Add to Home Screen.
On Android: Menu → Add to Home screen. The icon is the gold crown with purple gems.

After it's on the home screen, tapping it opens the app in standalone mode.
